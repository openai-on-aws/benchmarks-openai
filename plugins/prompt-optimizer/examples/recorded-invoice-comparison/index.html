What this run actually measures
36 bundled invoices imported. The comparison used 12 validation and 12 holdout cases on both models twice, on each backend. Four additional route checks used one reserved development case. The prompt was fixed throughout; OCR and prompt optimization were outside the study.
Timing, costs and comparability
Conversation time runs from the user turn to the returned answer. It includes authentication and network/provider time, and excludes worker setup/teardown, outer AgentCore dispatch, coordinator scheduling and grading. Cloud dispatch is the separate worker-invocation duration and includes transport and worker overhead; it is not added to conversation time.
The two backend runs were sequential, not a controlled experiment isolating hosting overhead. Held-out cloud workers had already handled validation trials. Costs use returned token usage and verified Standard US cross-Region list prices; they exclude AgentCore, S3, logging and human review charges.
