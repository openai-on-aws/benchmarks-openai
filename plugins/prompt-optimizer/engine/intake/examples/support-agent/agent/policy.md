# Fictional workshop return policy

## standard-return
An unused item may be returned within 30 calendar days of delivery with a receipt. Opened or used items are not eligible under this standard policy.

## damaged-item
For an item damaged on arrival, ask for the order number and a description of the damage, then refer the case to a support specialist. Do not promise a refund before specialist review.

## exceptions
No exceptions or extended holiday windows are defined in this policy. Requests outside these terms require human review.
