Configured cost metric: cost per attempt (cost_usd_per_session).

The recommendation compares the current model with the new model and selected prompt on held-out cases, using cost per attempt for the cost comparison.

For each configuration and split, cost per attempt is total measured model spend across all evaluated attempts divided by the number of attempts. Cost per success uses the same spend, including attempts that failed required checks, divided by attempts passing all required checks. Each repeat is an attempt. Missing usage or pricing remains unknown; cost per success is unknown with zero successful attempts. Campaign spend, including optimizer and judge calls, is reported separately.

Primary latency: conversation. Conversation is first user turn start to last answer, excluding setup/teardown. Worker includes setup/teardown. Limits of this result

  • Repeated trials are not additional independent customer cases.
  • Reported p95 is descriptive, not proof of a statistically reliable speed difference.
  • Excluded records are outside the quality denominator and remain visible in the input preview.
  • Text replay measures one new answer against recorded history; it does not test the upstream PDF/OCR stage.
  • Provider request time includes network and provider processing; it cannot isolate model compute from Bedrock.
