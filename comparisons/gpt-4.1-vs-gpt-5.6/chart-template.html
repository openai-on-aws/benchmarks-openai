How to read these charts

TTFT measures time to the first nonempty streamed text delta on final attempts where that event was observed. It includes incomplete responses that emitted text. Final-attempt duration includes terminal failures and local input rejections. Neither timing measure includes earlier retry durations or backoff.

Filled and open circles show p50 and p95, not confidence intervals. Timing and cost axes stay fixed for a workload across reasoning settings, but differ between workloads. No overall latency is inferred by averaging workload percentiles.

Spend sums recorded usage across all retained attempts, including retries. Hatching shows the conservative upper estimate for missing usage, not a statistical confidence interval or an exact billed total. Costs reflect the recorded pricing and configuration, not current price quotations.

The same GPT-4.1 baseline is repeated in low/high views. Run timing, some output ceilings and overlapping suite execution differ between none and low/high; this is a descriptive sensitivity comparison.
